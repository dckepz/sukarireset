# Sukari Reset

Welcome to the official repository for **Sukari Reset**, a premium health companion for Kenyans living with Type 2 diabetes and prediabetes.

---

## 🏗️ Project Structure

- `/` - PHP-based Marketing Website (entry point: `index.php`)
- `/views` - Website pages (Home, Membership, Payment)
- `/js` - Website logic and routing
- `/includes` - Shared website components (Navbar, Footer, Chat Widget)
- `/assets` - Images and static assets
- `/data` - Content data (`content.json`)
- `/api` - Vercel PHP functions

---

## 🚀 Development

The website is built with PHP and Vanilla JS/GSAP.

To run locally using PHP's built-in server:
```bash
php -S localhost:8000
```
Then visit `http://localhost:8000`.

---

## 🎨 Design System

- **Primary Emerald**: `#2D6A4F` / `#0A1710`
- **Brand Gold**: `#cfa85c`
- **Typography**: Outfit, Space Grotesk, Playfair Display

---

## 🚀 Deployment

The site is deployed on Vercel using the `vercel-php` runtime. Configuration is in `vercel.json`.
